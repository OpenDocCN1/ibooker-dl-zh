
# 1. 您会使用哪个 AWS 服务将文本翻译成不同的语言？

1. `Amazon Comprehend`
2. `Amazon Polly`
3. `Amazon Translate`
4. `Amazon Textract`

# 2. 亚马逊 Kendra 的用途是什么？

1. 它使用人工智能模型翻译外语。
2. 它将文本转换为语音。
3. 它使用人工智能创建财务报告。
4. 它提供了一个由人工智能驱动的搜索和检索系统，该系统处理自然语言查询。

# 3. 亚马逊 Kendra 的核心人工智能能力是什么？

1. 它从量子数据库中检索数据。
2. 它使用线性回归分析。
3. 它使用检索增强生成（RAG）来提高搜索准确性。
4. 它使用关键词匹配。

# 4. 亚马逊 Transcribe 做什么？

1. 它将 `spoken audio` 转换为书面文本。
2. 它将文本转换为另一种语言。
3. 它从文档中提取信息。
4. 它提供文本情感分析。

# 5. 亚马逊 Polly 的用途是什么？

1. 它将 `spoken audio` 转录成文本。
2. 它将文本翻译成其他语言。
3. 它从大型数据库中提取洞察力用于分析。
4. 它将文本转换为类似人类的语音。
