
# 变分自编码器（VAE）的梯度推导

## 对参数 θ 的梯度

首先，我们推导目标函数对参数 θ 的梯度。目标函数为：

```
∇_θ [ -KL(q_φ(z|x^(i)) || p(z)) + 𝔼_{q_φ(z|x^(i))}[log p_θ(x^(i)|z)] ]
```

根据梯度运算的线性性质，和的梯度等于各项梯度之和，因此：

```
∇_θ [ -KL(q_φ(z|x^(i)) || p(z)) + 𝔼_{q_φ(z|x^(i))}[log p_θ(x^(i)|z)] ]
= ∇_θ [ -KL(q_φ(z|x^(i)) || p(z)) ] + ∇_θ [ 𝔼_{q_φ(z|x^(i))}[log p_θ(x^(i)|z)] ]
```

由于第一项 `-KL(q_φ(z|x^(i)) || p(z))` 不包含参数 θ，其对 θ 的梯度为 0，因此我们得到：

```
∇_θ [ -KL(q_φ(z|x^(i)) || p(z)) + 𝔼_{q_φ(z|x^(i))}[log p_θ(x^(i)|z)] ]
= ∇_θ [ 𝔼_{q_φ(z|x^(i))}[log p_θ(x^(i)|z)] ]
```

接下来，利用期望的梯度与梯度的期望之间的关系（在满足一定条件下可以交换积分与求导顺序），我们可以将梯度算子移入期望内部：

```
∇_θ [ 𝔼_{q_φ(z|x^(i))}[log p_θ(x^(i)|z)] ]
= 𝔼_{q_φ(z|x^(i))}[ ∇_θ log p_θ(x^(i)|z) ]
```

最后，使用蒙特卡洛方法，用从 `q_φ(z|x^(i))` 中抽取的 n 个样本 `z_j` 来近似这个期望，得到标准的小批量梯度估计：

```
𝔼_{q_φ(z|x^(i))}[ ∇_θ log p_θ(x^(i)|z) ]
≈ (1/n) ∑_{j=1}^{n} ∇_θ log p_θ(x^(i)|z = z_j)
```

第一个等式源于一个事实，即一组项的梯度等于每个项的梯度之和。由于第一项不是 θ 的函数，它对 θ 的梯度为 0，导致我们得到第二个等式。从那里我们有了标准的小批量梯度估计推导。

## 对参数 φ 的梯度

对于 φ 的优化并不那么简单。如果我们尝试对 φ 做与 θ 相同的操作，我们会遇到一个意想不到的问题：

```
∇_φ [ -KL(q_φ(z|x^(i)) || p(z)) + 𝔼_{q_φ(z|x^(i))}[log p_θ(x^(i)|z)] ]
```

这里的问题在于，期望 `𝔼_{q_φ(z|x^(i))}[log p_θ(x^(i)|z)]` 本身依赖于参数 φ（因为采样分布 `q_φ` 是 φ 的函数），因此不能简单地将梯度算子移入期望内部。这就是变分自编码器中著名的“重参数化技巧”（reparameterization trick）所要解决的核心难题。
