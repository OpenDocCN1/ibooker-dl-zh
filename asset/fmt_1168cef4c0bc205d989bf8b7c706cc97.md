
# 推导过程

## 梯度展开

首先，我们对目标函数关于参数 `φ` 求梯度，得到以下表达式：

```
∇φ = -KL(qφ(z|x(i)) || p(z)) + ∇φ 𝔼qφ(z|x(i)) [log pθ(x(i)|z)]
```

将期望项展开为积分形式：

```
∇φ = -KL(qφ(z|x(i)) || p(z)) + ∇φ ∫ qφ(z|x(i)) log pθ(x(i)|z) dz
```

由于梯度作用于积分内部，我们可以将梯度移入积分：

```
∇φ = -KL(qφ(z|x(i)) || p(z)) + ∫ ∇φ qφ(z|x(i)) log pθ(x(i)|z) dz
```

## 重参数化技巧

在最后一步中，我们无法将第二项表示为期望。这是因为梯度是针对我们抽样的分布的参数。我们不能像对 `θ` 那样简单地交换期望和梯度的顺序。为了解决这个问题，我们做出以下观察：

利用对数导数的性质，我们可以将梯度的形式进行改写：

```
∇φ qφ(z|x(i)) = ∇φ qφ(z|x(i)) * (qφ(z|x(i)) / qφ(z|x(i)))
```

化简后得到：

```
= qφ(z|x(i)) * (∇φ qφ(z|x(i)) / qφ(z|x(i)))
```

进一步利用对数导数恒等式，最终得到：

```
= qφ(z|x(i)) ∇φ log qφ(z|x(i))
```

通过一点微积分和代数，我们得到了梯度的等价形式。如果我们将这种重述替换到我们卡住的步骤中，就可以将梯度重新表示为关于分布 `qφ(z|x(i))` 的期望形式，从而解决无法直接计算期望的问题。
