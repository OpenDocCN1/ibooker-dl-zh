
# 附录 B. 答案键

## 第三章：答案键

1. `C`: 内容审核是专门设计用于检测和过滤在线有害或不适当内容的 AI 工作负载。至于其他选项，知识挖掘从大量数据集中提取洞察，生成式 AI 产生新内容，而文档智能专注于从文档中提取数据。

2. `A`: 人工智能个性化旨在推荐与用户偏好和行为一致的内容，通过使交互更加相关来增强他们的体验。生成新图像（选项 `B`）是生成式 AI 的功能，而不是个性化。检测有害内容（选项 `C`）属于内容审核，它侧重于安全性而不是定制内容。分析人类语言（选项 `D`）是自然语言处理的一部分，而不是个性化。

3. `A`: 自然语言处理（`NLP`）是致力于分析、解释和生成人类语言的 AI 工作负载。内容审核（选项 `B`）专注于识别和过滤不适当的内容，而不是理解语言。计算机视觉（选项 `C`）处理识别和解释图像和视频，而不是文本。文档智能（选项 `D`）用于从文档中提取信息，但并不专门分析或生成语言本身。

4. `C`: 计算机视觉是使用光学字符识别（`OCR`）从图像中提取文本的 AI 工作负载。自然语言处理（`NLP`）专注于分析语言而不是图像内容，知识挖掘从数据中提取洞察，但不从图像中提取，生成式 AI 创建新内容而不执行 `OCR` 或文本提取任务。

5. `B`: 知识挖掘是用于从非结构化数据（如文本和视频）中揭示洞察的 AI 工作负载。文档智能（选项 `A`）专注于处理结构化文档，而不是广泛的非结构化数据分析。计算机视觉（选项 `C`）处理解释图像和视频，但不提取概括性的洞察。自然语言处理（选项 `D`）专注于语言任务，并不设计用于挖掘各种类型非结构化数据中的洞察。

6. `B`: 生成式 AI 是设计用于创建全新内容（如文本和图像）的工作负载。虽然自然语言处理（`NLP`）可以处理和生成人类语言，但它并不专注于生产原创的多媒体内容。同样，知识挖掘用于提取洞察，文档智能与现有文档一起工作——这些都不涉及生成新材料。

7. `A`: 分析文本 API 是 Azure AI 内容安全工具，专门用于检测文本中的有害内容。相比之下，分析图像 API 专注于扫描图像，自定义分类 API 有助于定义新的内容类别而不扫描文本，而 `Moderate Text API` 提供更广泛的审核，但不像 `Analyze Text` 那样进行针对性的有害内容检测。

8. `A`: 公平性是确保系统在所有人口群体中安全且公平运行的负责任 AI 原则。透明度（选项 `B`）关注的是使 AI 系统对用户可理解，而不一定是消除偏见。包容性（选项 `C`）旨在使 AI 对广泛的用户可访问，但并不保证结果的公平性。问责制（选项 `D`）确保开发者对 AI 的行为负责，但并不具体针对群体间的平等对待。

9. `C`: 计算机视觉是专注于分析和解释图像和视频等视觉内容的 AI 工作负载。自然语言处理（`NLP`）（选项 `A`）关注的是语言处理，而不是视觉分析。知识挖掘（选项 `B`）从数据中揭示洞察，但不专门从事解释视觉内容。生成式 AI（选项 `D`）创建新内容，如文本或图像，但主要不是专注于分析现有视觉媒体。

10. `D`: 文档智能是专门设计用于处理大量文档并提取关键信息的 AI 工作负载。相比之下，自然语言处理（`NLP`）专注于理解和生成人类语言，生成式 AI 创建新内容而不是处理文档，内容审核过滤有害材料但不处理文档数据提取。

## 第四章：答案关键

1. `C`: 在机器学习中，回归分析的主要目的是根据输入变量预测数值结果。分类（选项 `A`）将数据分类到不同的类别，而不是预测连续值。聚类（选项 `B`）将相似的数据点分组而不进行数值预测。图像和视频分析（选项 `D`）是由深度学习模型处理的任务，而不是回归分析。

2. `B`: 基于特征预测房价是监督学习的例子，因为它涉及使用标记数据来训练模型以预测特定结果。相比之下，`K-means` 和客户细分是无监督方法，它们将数据分组而没有预定义的标签，异常检测可以根据上下文属于无监督或半监督学习。

3. `B`: 逻辑回归是常用于二分类任务中预测两类之间概率的算法。线性回归（选项 `A`）预测的是连续值，而不是概率。决策树（选项 `C`）可以用于数据分类，但并不天然输出概率分数。`K-means`（选项 `D`）用于聚类相似的数据点，而不是用于分类或概率预测。

4. `C`: `F1` 分数涉及精确度和召回率之间的平衡，提供了一个单一指标，该指标同时考虑了假阳性和假阴性。区分类别（选择 `A`）通常通过曲线下面积（`AUC`）来衡量，而不是 `F1` 分数。预测误差的平均值（选择 `B`）使用均方误差（`MSE`）或平均绝对误差（`MAE`）等平均误差指标来评估，这些指标适用于回归任务。总准确率（选择 `D`）衡量整体正确性，但并不像 `F1` 分数那样具体平衡精确度和召回率。

5. `B`: 推理是机器学习工作流程中的一个步骤，其中训练好的模型用于对新数据进行预测。训练侧重于开发模型学习模式的能力，验证用于评估性能，而数据准备涉及清理和组织数据以便在模型中使用——这些都不直接产生像推理那样产生的预测。

6. `D`: `K-means` 聚类与无监督学习相关联，其中算法根据相似性对数据进行分组，而不依赖于标记示例。监督学习（选择 `A`）需要标记数据用于训练，而半监督学习（选择 `B`）使用标记和无标记数据的混合。强化学习（选择 `C`）侧重于通过行动和奖励进行学习，而不是聚类或分组数据。

7. `B`: 决定系数（`R²`）衡量回归模型解释数据变化的能力。均方误差（`MSE`）（选择 `A`）关注大预测误差的幅度，而不是解释能力。均方根误差（`RMSE`）（选择 `C`）以数据的原始单位报告预测误差。平均绝对误差（`MAE`）（选择 `D`）平均预测值和实际值之间的绝对差异，但并不表明模型解释了多少方差。

8. `B`: 预测性插补通过根据可用数据中发现的模式估计值来解决缺失数据。均值插补（选择 `A`）简单地用均值替换缺失值，而不考虑潜在关系。删除不完整的数据（选择 `C`）可能会引入偏差并降低数据集的质量。数据归一化（选择 `D`）调整数据的尺度，但不处理缺失值。

9. `C`: 机器学习中分类的主要目标是根据标记数据将数据点分配到预定义的类别中。识别未标记数据中的隐藏模式（选择 `A`）是聚类的目的，而不是分类。预测数值结果（选择 `B`）由回归任务处理。生成新内容（选择 `D`）是生成式 AI 的功能，而不是分类。

10. `C`: 聚类是机器学习中用于将相似数据点分组的技术，而不依赖于标签。回归（选项 `A`）专注于预测数值，而不是分组数据。分类（选项 `B`）需要标记示例来将数据点分配到预定义的类别。深度学习（选项 `D`）处理复杂任务，如图像或语音识别，但并不专注于分组未标记数据。

## 第五章：答案关键

1. `B`: 回归是机器学习中常用的一种技术，它基于已知变量来预测数值结果。分类（选项 `A`）将数据分配到类别中，而不是预测连续值。聚类（选项 `C`）将相似的数据点分组，而不进行预测。深度学习（选项 `D`）可以执行许多任务，但并不专注于回归那样的直接数值预测。

2. `C`: 均方绝对误差（`MAE`）衡量预测的平均误差，无论偏差是正还是负，都同等对待。均方误差（`MSE`）（选项 `A`）通过平方来夸大较大的误差。确定系数（`R²`）（选项 `B`）衡量模型解释数据方差的能力，而不是误差的大小。均方根误差（`RMSE`）（选项 `D`）以原始单位报告误差，但仍然通过平方强调较大的误差。

3. `B`: 逻辑回归是最常用的算法之一，用于估计二元结果的概率，因为它输出介于 0 和 1 之间的值来表示类别概率。`K-means` 聚类不适用于此任务，因为它在分组数据时不预测概率。线性回归估计连续值，而设计用于分类，决策树可以分类但不提供内在的概率估计。

4. `B`: Azure 的自动化机器学习（`AutoML`）主要支持监督学习，专注于需要标记数据的任务，如分类和回归。它不专注于强化学习或聚类等无监督学习方法，也不直接实现遗传算法。`AutoML` 旨在自动化在监督学习框架内构建和调整模型的过程。

5. `B`: 在多类分类问题中，使用一对一（`OVR`）方法为每个类别构建一个单独的二进制分类器，允许模型区分一个类别与其他所有类别。`K-means` 是一种聚类方法，不适用于分类任务。多项式算法处理单个模型中的所有类别，虽然逻辑回归可以适应多类问题，但它并非天生设计用于构建多个二元分类器，如 `OVR`。

6. `B`: `AutoML` 是 Azure 机器学习功能，它自动化了尝试多个算法和调整超参数的过程，以找到最佳模型。自定义脚本执行（选择 `A`）需要手动编码，没有自动模型选择。数据集存储（选择 `C`）旨在组织和管理工作数据，而不是用于训练或选择模型。部署管道（选择 `D`）用于管理和自动化模型的部署，而不是选择或优化它们。

7. `C`: 召回率是评估指标，用于衡量分类模型正确识别的实际正例的比例。准确率（选择 `A`）考虑了所有正确的预测，而不仅仅是正例。精确率（选择 `B`）衡量预测的正例中有多少实际上是正确的，而不是捕获所有实际的正例。`F1` 分数（选择 `D`）将精确率和召回率合并为单一指标，但并不专注于真正的正例识别。

8. `C`: 聚类是一种机器学习技术，用于根据相似性将数据点分组，而不依赖于先前的标签。监督学习（选择 `A`）需要标记的数据进行训练。分类（选择 `B`）将数据分配到预定义的类别，而不是自然分组。回归（选择 `D`）预测数值结果，而不是根据特征相似性将数据组织成簇。

9. `C`: 均方误差（`MSE`）是回归指标，用于衡量预测值和实际值之间平方差的平均值。平均绝对误差（`MAE`）（选择 `A`）计算绝对差值的平均值，而不对它们进行平方。均方根误差（`RMSE`）（选择 `B`）是 `MSE` 的平方根，而不是直接报告平方差。`R²` 分数（选择 `D`）衡量模型解释了多少方差，而不是平均误差幅度。

10. `C`: 神经网络是由多层组成的深度学习结构，通过处理数据来做出复杂的预测。支持向量机（`SVMs`）（选择 `A`）是主要关注分类的单层算法。决策树（选择 `B`）使用分支结构进行决策，而不是分层处理。`K` 最近邻（选择 `D`）通过计算到附近点的距离来做出预测，而不使用分层架构。

## 第六章：答案键

1. `B`: 像素是计算机视觉中数字图像的基本构建块，形成了一个由单个彩色点组成的网格。虽然过滤器可以修改这些像素，但它们并不构成图像本身。神经网络分析像素中的数据，标签有助于对图像进行分类，但它们都不像像素那样代表图像网格的结构。

2. `B`: 在目标检测中，边界框用于确定和勾勒图像中对象的位置。`OCR`（选择 `A`）旨在从图像中读取文本，而不是找到对象位置。人脸检测（选择 `C`）专门识别人脸，但不定位其他类型的对象。图像分类（选择 `D`）对图像中存在的内容进行分类，但不会确定对象的位置。

3. `C`: 在计算机视觉中，卷积的主要目的是识别像素数据中的模式，如边缘、纹理和形状。它不用于像颜色反转或图像缩放这样的任务，也不直接分配标签。相反，卷积作为关键的特征提取步骤，在分类或标记等高级任务之前进行。

4. `B`: Azure AI Vision 是专门处理计算机视觉任务（如目标检测和面部分析）的服务。Azure Cognitive Search 专注于查找和组织数据，Azure Machine Learning 支持通用机器学习工作流程，但在视觉任务方面缺乏专业化，Azure Kubernetes Service 用于容器编排，而不是处理视觉数据。

5. `B`: 卷积神经网络（`CNNs`）由于其通过卷积层提取特征的能力，是计算机视觉任务（如图像分类）中最常用的神经网络。循环神经网络（`RNNs`）更适合处理序列数据，如文本或时间序列。生成对抗网络（`GANs`）主要用于图像生成，而不是分类，而转换器通常应用于自然语言处理和多模态任务。

6. `C`: 池化层是卷积神经网络（`CNN`）的组成部分，它在保留重要细节的同时减小特征图的大小。卷积层（选择 `A`）提取特征但不减小特征图大小。全连接层（选择 `B`）连接层间的神经元，但不调整特征图的大小。激活函数（选择 `D`）向模型引入非线性，但不会改变特征图的维度。

7. `B`: 光学字符识别（`OCR`）是用于读取和解释图像中文本的计算机视觉技术。图像分类（选择 `A`）对图像的整体内容进行分类，但不提取文本。人脸检测（选择 `C`）识别人脸而不解释文本信息。目标检测（选择 `D`）在图像中找到对象，但不专注于阅读或理解文本。

8. `B`: 与人工智能中的人脸检测和分析相关的首要伦理问题是隐私和同意问题。这源于在未获得个人知情同意的情况下收集和使用人脸数据的可能性。其他考虑因素，如颜色准确性和计算成本，是技术问题而不是伦理问题。虽然数据集有限可能会影响模型性能，但这不是主要的伦理问题。

9. `B`: 在 Azure 的 AI Vision Studio 中，与目标检测结果一起提供置信度分数，以表明模型对其预测有多确定。这个分数量化了模型在识别对象时的置信水平。像素计数与置信度无关，边界框颜色是视觉辅助工具，而文件类型与模型对其检测的确定性无关。

10. `C`: 卷积神经网络（`CNNs`）中的激活函数在图像识别过程中起着至关重要的作用，通过帮助为预测分配概率，使模型能够做出最终决策。它们将非线性引入网络，这对于学习复杂模式至关重要。虽然边缘检测和图像尺寸减少分别由卷积层和池化层处理，而颜色处理与之无关，但激活函数对于产生有意义的分类输出是关键。

## 第七章：答案关键

1. `C`: Azure AI Translator 是 Azure 服务，旨在将文本即时翻译成多种语言。Azure AI Language（选择 `A`）专注于分析和理解文本，而不是翻译。Azure AI Speech（选择 `B`）用于将语音转换为文本和 vice versa，而不是用于书面文本翻译。Azure AI Sentiment（选择 `D`）分析文本的情感基调，但不提供翻译服务。

2. `C`: 命名实体识别（`NER`）在自然语言处理（`NLP`）中的主要功能是识别和分类特定的实体，如姓名、日期和地点。情感分析（选择 `A`）专注于解释文本的情感基调，而不是识别实体。语言检测（选择 `B`）识别文本中使用的语言，但不提取实体。关键短语提取（选择 `D`）突出显示主要思想或主题。

3. `C`: Azure AI Speech 中的实时语音转文本功能能够即时将现场音频转录成文本。文本到语音（选择 `A`）从书面文本生成语音输出，而不是转录现场音频。摘要（选择 `B`）浓缩书面内容，与音频转录无关。自定义翻译器（选择 `D`）定制文本翻译，但不处理将现场语音转换为文本。

4. `C`: 自然语言处理（`NLP`）中的分词是指将文本分解成单个单词或短语，称为标记，以便对文本进行分析的过程。它不涉及为实体分配标识符或将文本转换为语音，这些是独立的功能。此外，语言检测识别文本中使用的语言，但不会像分词那样将其分割成有意义的组件。

5. `B`: Azure 的关键短语提取功能用于识别和突出显示文本中的主要概念或主题。特定实体的分类（选项 `A`）是命名实体识别（`NER`）的作用，而不是关键短语提取。语言检测（选项 `C`）确定文档的语言，但不会识别关键思想。情感分析（选项 `D`）评估文本的情感基调，而不是关注其主要概念。

6. `C`: `PII` 检测是 Azure NLP 功能，旨在识别和删除敏感信息，如社会保障号码。语言检测（选项 `A`）识别文本的语言，但不会检测敏感细节。关键短语提取（选项 `B`）突出显示主要主题或主题，而不是识别敏感数据。情感分析（选项 `D`）评估文本的情感基调，而不是检查个人识别信息的存在。

7. `B`: 停用词移除是 NLP 过程，用于消除对文本语义价值贡献较小的常见词，如“the”和“an”。词形还原（选项 `A`）将单词还原为其基本形式，但不会移除它们。分词（选项 `C`）将文本分割成单个单词或标记，而不过滤掉常见术语。频率分析（选项 `D`）衡量单词出现的频率，但不会消除非必要单词。

8. `B`: Azure AI 语言工作室中的实体链接功能自动将“巴黎”等实体与特定引用相关联，帮助区分类似术语，如“巴黎，法国”和“巴黎·希尔顿”。实体识别（选项 `A`）识别实体，但不会将它们与特定引用相关联。语言检测（选项 `C`）确定文本的语言，而不是链接实体。摘要（选项 `D`）压缩文本，但不会将实体与独特的引用关联。

9. `B`: Azure AI 语音中的快速转录 API 旨在提供快速、同步的音频文件转录。翻译（选项 `A`）由 Azure AI 翻译器处理，而不是快速转录 API。情感检测（选项 `C`）与此功能无关，专注于分析情感基调。文本到语音转换（选项 `D`）从文本生成语音输出，而不是将音频转录成文本。

10. `B`: Azure 中的摘要功能用于通过从大量文本中提取关键句子来创建简洁的摘要。文本到语音（选项 `A`）将书面文本转换为音频，但不会进行摘要。语言检测（选项 `C`）识别文本的语言而不是压缩其内容。实体识别（选项 `D`）识别特定的实体，如姓名或地点，但不会提取或总结主要思想。

## 第八章：答案关键

1. `B`: `DALL-E` 是 Azure 生成 AI 功能，可以根据文本提示创建独特的图像。语义搜索（选项 `A`）根据意义检索信息，但不生成图像。内容审查（选项 `C`）用于检测不适当的内容，而不是创建视觉内容。逼真的对话创作（选项 `D`）侧重于产生逼真的对话，而不是生成图像。

2. `C`: 在转换器模型中，嵌入的作用是编码单词之间的语义关系，创建一个有意义的语言表示，帮助模型理解上下文和意义。它们不用于检测有害内容，这由内容审查工具处理，也不直接负责翻译语言或生成个性化推荐，这些依赖于不同的机制和数据输入。

3. `D`: 编码器块是转换器模型中负责解释输入文本上下文的组件。虽然嵌入有助于表示单词之间的关系，而自注意力突出了重要的单词连接，但处理输入数据以上下文方式的是编码器块。相比之下，解码器块专注于生成新的文本序列，而不是理解输入。

4. `C`: 上下文问答是专为提供自然准确响应客户问题和咨询而设计的 AI 工作负载。图像生成（选项 `A`）侧重于根据提示创建视觉内容，而不是回答问题。摘要（选项 `B`）会压缩长内容，但不参与对话。个性化推荐（选项 `D`）为用户定制内容，但不适用于交互式对话。

5. `C`: 在 Azure 的 AI 中，多头注意力指的是在转换器模型内从多个角度分析单词之间的关系。标记生成（选项 `A`）是由解码器块处理的独立功能。异常检测（选项 `B`）识别数据中的异常模式。翻译（选项 `D`）涉及在语言之间转换文本，并且与多头注意力机制不同。

6. `B`: 大型语言模型（`LLMs`）由于其大小和训练所使用的数据量，通常需要大量的内存和存储。相比之下，小型语言模型（`SLMs`）通常提供更快的响应时间，消耗更少的能源，并且更容易在本地部署。

7. `B`: 使用 Azure OpenAI 的模型目录的主要优势是获得访问各种预训练、高性能模型的机会，适用于不同的应用。快速训练时间（选项 `A`）不是模型目录的功能，因为它专注于现成的模型。专用于 OpenAI 模型（选项 `C`）的说法不准确，因为目录包括更广泛范围的模型。它也不限于图像生成（选项 `D`），支持许多不同的 AI 任务。
