
```py
def pad_sequences(sequences, maxlen):
    return [seq + [0] * (maxlen - len(seq)) if len(seq) < maxlen 
            else seq[:maxlen] for seq in sequences]
```

这个函数将把序列中的每个数组重塑为最大长度数组的长度。所以，假设我们用以下代码对句子进行序列化后填充它们：

```py
for sentence in sentences:
  seq = text_to_sequence(sentence, vocab)
  padded_seq = pad_sequences([seq], maxlen=10)  # Example maxlen
  print(padded_seq)
```

然后，输出将看起来像这样：

```py
[[1, 2, 3, 4, 5, 0, 0, 0, 0, 0]]
[[1, 2, 3, 6, 5, 0, 0, 0, 0, 0]]
[[2, 7, 4, 8, 0, 0, 0, 0, 0, 0]]
[[9, 10, 11, 12, 13, 14, 15, 1, 0, 0]]
```

现在，由于`maxlen`参数，每个序列的长度都是 10。这是一个相当简单的实现，如果你更认真地使用它，你可能希望在此基础上进行构建。例如，你可能想要考虑如果你有一个比最大长度还长的序列会发生什么。目前，它会在最大长度之后截断一切，但你可能希望它表现出不同的行为！

还要注意，如果你使用的是像我们之前展示的 BERT 这样的现成分词器，那么这些功能中的许多可能已经可用，所以请确保进行实验。

# 移除停用词和文本清洗

在下一节中，你将查看一些真实世界的数据集，你会发现其中往往有一些你*不希望*在数据集中的文本。你可能还希望过滤掉所谓的*停用词*——如“the”、“and”和“but”——它们太常见且不增加任何意义。你可能会在文本中遇到很多 HTML 标签，并且有一个干净的方法来移除它们。你可能还想过滤掉粗俗的词语、标点符号或名字。稍后，我们将探索一个包含某人用户 ID 的推文数据集，我们希望过滤掉这些 ID。

虽然每个任务都是基于你的文本语料库而不同的，但你可以通过以下三种主要方式来程序化地清理你的文本。

## 移除 HTML 标签

你可以做的第一件事是移除 HTML 标签，幸运的是，有一个名为 BeautifulSoup 的库可以使这个过程变得简单。例如，如果你的句子包含 HTML 标签如`<br>`，你可以通过以下代码移除它们：

```py
from bs4 import BeautifulSoup
soup = BeautifulSoup(sentence)
sentence = soup.get_text()
```

## 移除停用词

第二件事是移除停用词，一个常见的方法是有一个停用词列表，并通过移除停用词的实例来预处理你的句子。以下是一个简化的例子：

```py
stopwords = ["a", "about", "above", ... "yours", "yourself", "yourselves"]
```

你可以在本章的一些[在线示例](https://github.com/lmoroney/PyTorch-Book-FIles)中找到一个完整的停用词列表。

然后，当你遍历你的句子时，你可以使用如下代码来从你的句子中移除停用词：

```py
words = sentence.split()
filtered_sentence = ""
for word in words:
    if word not in stopwords:
        filtered_sentence = filtered_sentence + word + " "
sentences.append(filtered_sentence)
```

## 移除标点符号

第三件事是移除标点符号，你想要这样做是因为标点符号可能会误导停用词过滤器。我们刚刚展示的那个方法寻找的是被空格包围的单词，所以它不会发现紧随句号或逗号之后的停用词。

使用 Python 字符串库提供的翻译函数可以轻松解决这个问题。但请注意，这种方法可能会影响 NLP 分析，尤其是在检测情感时。

该库还包含一个名为 `string.punctuation` 的常量，其中包含了一系列常见的标点符号，因此要从单词中移除它们，你可以这样做：

```py
import string
table = str.maketrans('', '', string.punctuation)
words = sentence.split()
filtered_sentence = ""
for word in words:
    word = word.translate(table)
    if word not in stopwords:
        filtered_sentence = filtered_sentence + word + " "
sentences.append(filtered_sentence)
```

在这里，在过滤停用词之前，该常量会从句子中的每个单词中移除标点符号。所以，如果分割一个句子得到单词 *it*，该单词将被转换为 *it*，然后作为停用词被移除。然而，请注意，在进行此操作时，你可能需要更新你的停用词列表。这些列表中通常包含缩写词和缩写，如 *you’ll*，翻译器会将 *you’ll* 改为 *youll*。因此，如果你想过滤掉这些单词，你需要更新你的停用词列表以包括它们。

按照这三个步骤操作，你将得到一组更加干净的文本以便使用。但当然，每个数据集都会有其独特的特性，你需要与这些特性打交道。

```py
from collections import Counter
import os

# Simple tokenizer
def tokenize(text):

# Build vocabulary
def build_vocab(path):
    counter = Counter()
    for folder in ["pos", "neg"]:
        folder_path = os.path.join(path, folder)
        for filename in os.listdir(folder_path):
            with open(os.path.join(folder_path, filename), 'r', 
                                   encoding='utf-8') as file:
                counter.update(tokenize(file.read()))
    return {word: i+1 for i, word in enumerate(counter)} # Starting index from 1

```

这段代码非常直接，它只是逐个读取每个文件，并将新发现的单词添加到词汇表中，为每个单词分配一个新的标记值。通常，你只想对训练数据进行此操作，理解到测试数据中会有不在训练数据中的单词，并且它们将使用 OOV（未知标记）进行分词。

现在，让我们更新分词器，按照单词频率的顺序进行分词。这次更新改变了分词器，使其将所有文件加载到内存中，并计算每个单词的实例以获取频率表：

```py
# Build vocabulary
def build_vocab(path):
    counter = Counter()
    for folder in ["pos", "neg"]:
        folder_path = os.path.join(path, folder)
        for filename in os.listdir(folder_path):
            with open(os.path.join(folder_path, filename), 'r', 
                                   encoding='utf-8') as file:
                counter.update(tokenize(file.read()))

    # Sort words by frequency in descending order
    sorted_words = sorted(counter.items(), key=lambda x: x[1], reverse=True)

    # Create vocabulary with indices starting from 1
    vocab = {word: idx + 1 for idx, (word, _) in enumerate(sorted_words)}
    vocab['<pad>'] = 0  # Add padding token with index 0
    return vocab
```

然后，我们可以将词汇表输出为这个频率表。由于词汇表太大，无法显示整个索引，但这里列出了前 20 个单词。请注意，分词器按照数据集中单词的频率顺序列出它们，因此像 *the*、*and* 和 *a* 这样的常用词被索引：

```py

'this': 9, 'that': 10, 'it': 11, '/><br': 12, 'was': 13, 'as': 14,
'for': 15, 'with': 16, 'but': 17, 'on': 18, 'movie': 19, 'his': 20,
```

这些是停用词，如前文所述。这些词的存在可能会影响你的训练精度，因为它们是最常见的单词，而且它们没有区分性（即，它们可能存在于正面和负面评论中），因此它们给我们的训练增加了噪声。

还要注意，*br* 也包含在这个列表中，因为在这个语料库中它常用作 `<br>` HTML 标签。

你还可以更新代码以使用 `BeautifulSoup` 来删除 HTML 标签，并且你可以按照以下方式从给定的列表中删除停用词。为此，你可以更新分词器，使用 `BeautifulSoup` 来删除 HTML 标签：

```py
# Simple tokenizer
from bs4 import BeautifulSoup

# Note that the list of stopwords is defined in the source code. 
# It’s an array of words. You can define your own or just get the one from 
# the book’s github.

def tokenize(text):
    soup = BeautifulSoup(text, "html.parser")
    cleaned_text = soup.get_text()  # Extract text from HTML
    return [word.lower() for word in cleaned_text.split() if word.lower() 
            not in stopwords]
```
