## Adam—结合动量和 RMSProp

在结束我们对现代优化器的讨论之前，我们讨论最后一个算法—Adam。从精神上讲，我们可以将 Adam 看作是 RMSProp 和动量的变体组合。

基本思想如下。我们希望跟踪梯度的指数加权移动平均（基本上是经典动量中的速度概念），我们可以表示如下：

**m**[*i*] = β[1]**m**[*i* – 1] + (1 – β[1])**g**[i]

这是我们对我们称之为梯度的 *第一矩* 或 𝔼[𝐠ᵢ] 的近似。类似于 RMSProp，我们可以维护历史梯度的指数加权移动平均值。这是我们对我们称之为梯度的 *第二矩* 或 𝔼[𝐠ᵢ ⊙ 𝐠ᵢ] 的估计：

𝐯ᵢ = β₂𝐯ᵢ₋₁ + (1 - β₂)𝐠ᵢ ⊙ 𝐠ᵢ

然而，事实证明这些估计相对于真实矩是有偏差的，因为我们从将两个向量初始化为零向量开始。为了纠正这种偏差，我们为这两个估计推导了一个校正因子。在这里，我们描述了对二阶矩的估计的推导。对于第一矩的推导，与此处类似的推导留作练习。

我们首先通过所有过去梯度的估计来表达二阶矩的估计。这是通过简单地展开递归关系来完成的：

𝐯ᵢ = β₂𝐯ᵢ₋₁ + (1 - β₂)𝐠ᵢ ⊙ 𝐠ᵢ

𝐯ᵢ = β₂^(i-1)(1 - β₂)𝐠₁ ⊙ 𝐠₁ + β₂^(i-2)(1 - β₂)𝐠₂ ⊙ 𝐠₂ + ... + (1 - β₂)𝐠ᵢ ⊙ 𝐠ᵢ

𝐯ᵢ = (1 - β₂)∑ₖ₌₁ᵢ β^(i-k)𝐠ₖ ⊙ 𝐠ₖ

然后，我们可以取两边的期望值，以确定我们的估计 𝔼[𝐯ᵢ] 如何与 𝔼[𝐠ᵢ ⊙ 𝐠ᵢ] 的真实值相比：

𝔼[𝐯ᵢ] = 𝔼[(1 - β₂)∑ₖ₌₁ᵢ β^(i-k)𝐠ₖ ⊙ 𝐠ₖ]

我们还可以假设 𝔼[𝐠ₖ ⊙ 𝐠ₖ] ≈ 𝔼[𝐠ᵢ ≈ 𝐠ᵢ] 因为即使梯度的二阶矩相对于历史值发生了变化，β₂ 应该被选择，以便旧的梯度二阶矩基本上衰减到不相关。因此，我们可以进行以下简化：

𝔼[𝐯ᵢ] ≈ 𝔼[𝐠ᵢ ⊙ 𝐠ᵢ](1 - β₂)∑ₖ₌₁ᵢ β^(i-k)

𝔼[𝐯ᵢ] ≈ 𝔼[𝐠ᵢ ⊙ 𝐠ᵢ](1 - β₂ⁱ)
