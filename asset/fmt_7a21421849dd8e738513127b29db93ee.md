## 常见问题

### 1. 在配置亚马逊 Bedrock 中的图像/视频游乐场时，“负面提示”是什么？

- 这增加了模型的温度。
- 它生成黑白图像。
- 它指定了您想要从图像或视频中排除的元素。
- 这减小了图像的大小。

### 2. 在亚马逊 Bedrock 的模型目录中，模态过滤器的作用是什么？

- 过滤器允许用户按许可类型对模型进行排序。
- 它根据语言支持过滤模型。
- 过滤器识别支持无服务器部署的模型。
- 它根据输入和输出类型（如文本、图像、音频和多模态）对模型进行分类。

### 3. 对于亚马逊 Bedrock 中的模型，为什么你会增加温度设置？

- 为了生成确定性内容
- 为了制作视频
- 为了生成创意内容
- 为了总结信息

### 4. 对于亚马逊 Bedrock 中的模型配置文件，你通常会找到什么类型的信息？

- 所使用的 GPU 类型
- 版本，发布日期，部署类型，模态，和模型 ID
- 只有许可信息
- 数据集

### 5. 你需要做什么才能访问默认未启用的亚马逊 Bedrock 中的基础模型（FMs）？

- 启用“按需”并重新启动会话。
- 提交一个包含用例详细信息的模型访问请求表单。
- 完成 AWS 认证考试。
- 在你自己的电脑上下载模型。
