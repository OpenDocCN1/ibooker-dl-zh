
由于`A`不保证是方阵，我们通常不能取其行列式或逆。所以，通常的`A^(-1)`是不工作的。在这个时候，我们注意到，尽管不能取逆，但矩阵转置总是可能的。让我们将方程的两边乘以`A^T`：

`Ax = b ⇔ A^TAx = A^Tb`

注意到`A^TA`是一个方阵：其维度是`(m×n) × (n×m) = m × m`。暂时不进行证明，我们假设它是可逆的。那么

`Ax = b ⇔ A^TAx = A^Tb ⇔ x = (A^TA)^(-1)A^Tb`

嗯嗯，还不错；我们似乎找到了一些东西。事实上，我们刚刚推导出了矩阵`A`的*伪逆*，表示为`A^+ = (A^TA)^(-1)A^T`。与逆矩阵不同，伪逆不需要矩阵是方阵且行线性无关。与常规线性系统类似，我们得到（可能非方阵）方程组的解为`Ax = b ⇔ x = A^+b`。

基于伪逆的解实际上最小化了误差`||Ax − b||`。我们将在第 2.12.5 节中提供一个直观的证明。同时，鼓励你编写 Python 代码来评估`(A^TA)^(-1)A^Tb`并验证它大约给出了方程 2.18 预期的答案。

### 2.12.5 矩阵的伪逆：一种美丽的几何直觉

## 2.13 特征值和特征向量：机器学习的瑞士军刀

机器学习和数据科学都是关于在大量高维数据中寻找模式。输入是第 2.1 节中介绍的高维空间中的特征向量。每个特征向量可以看作是输入实例的特征空间描述符中的一个点。有时我们会转换这些特征向量——将特征点映射到一个更友好的空间——通过降低维度来简化数据。这是通过消除数据中变化很少的轴来实现的。特征值和特征向量是机器学习工程师或数据科学家在简化数据和寻找大量多维数据中的广泛模式时的宝贵工具。在第四章中，我们将研究如何使用这些工具来简化数据和在大量多维数据中寻找广泛模式。

让我们先非正式地看看特征向量。它们是方阵的性质。如前所述，矩阵可以看作是线性变换，它将一个空间中的向量（点）映射到相同或不同空间中的不同向量（点）。但典型的线性变换会留下一些空间中的点（几乎）不受影响。这些点被称为*特征向量*。它们是变换的重要物理方面。让我们看一个简单的例子。假设我们在 3D 空间中围绕`Z`-轴（见图 2.13）旋转点。`Z`-轴上的点在旋转后仍将保持在原地。一般来说，旋转轴上的点在旋转后不会移动。旋转轴是旋转变换的特征向量。

![图片](img/CH02_F13_Chaudhury.png)

图 2.13 在旋转过程中，旋转轴上的点位置不变。

将这个想法扩展，当用矩阵`A`对向量`x`进行*变换*时，是否存在不改变（至少在方向上）的向量？结果是肯定的。这些就是所谓的*特征向量*——当通过矩阵`A`进行线性变换时，它们不会改变方向。为了更精确，如果`e`是方阵`A`的特征向量，⁵ 则有

`Ae = λe`

因此，线性变换（即，矩阵`A`的乘法）改变了`e`的长度，但没有改变其方向，因为`λe`与`e`平行。

我们如何获得`λ`和`e`？嗯，

`Ae = λe`

⇔ `Ae - λe = 0`

⇔ `(A - λI)e = 0`

其中`I`表示单位矩阵。

当然，我们只对非平凡解感兴趣，其中`e ≠ 0`。在这种情况下，`A – λI`不能是可逆的，因为如果是的话，我们可以得到矛盾的解`e = (A – λI)^(–1)0 = 0`。因此，`(A − λI)`是不可逆的，这意味着行列式

`det(A − λI) = 0`

对于一个`n × n`矩阵`A`，这会产生一个`n`次的多项式方程，对于未知数`λ`有`n`个解。*因此，一个`n × n`矩阵有 n 个特征值，不一定都是不同的*。

### 2.13.1 特征向量和线性无关

对应于不等特征值的矩阵的特征向量是线性无关的。让我们来证明这一点以获得一些洞察。设`λ[1]`，`e[1]`和`λ[2]`，`e[2]`是矩阵`A`的特征值，特征向量对，其中`λ[1] ≠ λ[2]`。那么

`Ae[1] = λ[1]e[1]`

`Ae[2] = λ[2]e[2]`

如果可能的话，让存在两个常数`α[1]`和`α[2]`使得

`α[1]e[1] + α[2]e[2] = 0`

方程式 2.24

换句话说，假设两个特征向量是线性相关的。我们将证明这个假设会导致不可能的情况。

将方程 2.24 乘以`A`，我们得到

`α[1]Ae[1] + α[2]Ae[2] = 0`

⇔ `α[1]λ[1]e[1] + α[2]λ[2]e[2] = 0`

此外，我们还可以将方程 2.24 乘以`λ[2]`。因此我们得到

`α[1]λ[1]e[1] + α[2]λ[2]e[2] = 0`

`α[1]λ[2]e[1] + α[2]λ[2]e[2] = 0`

相减，我们得到

`α[1]λ[1]e[1] - α[1]λ[2]e[1] = 0`

即`α[1](λ[1] - λ[2])e[1] = 0`

根据假设，`α[1] ≠ 0`，`λ[1] ≠ λ[2]`并且`e[1]`不是全零。因此，它们的乘积不可能为零。我们的原始假设（两个特征向量线性相关）一定是错误的。
