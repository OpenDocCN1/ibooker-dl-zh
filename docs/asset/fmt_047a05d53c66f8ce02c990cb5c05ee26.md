
# 变分推断与ELBO推导

## 边际似然的分解

对于单个数据点 \(x^{(i)}\)，其边际似然可以分解为关于潜在变量 \(z\) 的函数形式。具体推导过程如下：

\[
\begin{aligned}
\log p(x^{(i)}) &= \mathbb{E}_{q_\phi(z|x^{(i)})} \left[ \log p(x^{(i)}, z) - \log p(z|x^{(i)}) + \log q_\phi(z|x^{(i)}) - \log q_\phi(z|x^{(i)}) \right] \\
&= \mathbb{E}_{q_\phi(z|x^{(i)})} \left[ \log \frac{p(x^{(i)}, z)}{q_\phi(z|x^{(i)})} \right] + \mathbb{E}_{q_\phi(z|x^{(i)})} \left[ \log \frac{q_\phi(z|x^{(i)})}{p(z|x^{(i)})} \right] \\
&= \text{ELBO} + \text{KL}(q_\phi(z|x^{(i)}) \| p(z|x^{(i)}))
\end{aligned}
\]

### 推导步骤说明

1. **第一步**：将单个示例 \(x^{(i)}\) 的边际似然表达为示例本身和潜在因子 \(z\) 的函数。边际似然可以分解为联合分布 \(p(z, x^{(i)})\) 和条件分布 \(p(z|x^{(i)})\) 的商。对数函数使我们能够将这个商分解为两个项的对数之间的差异。

2. **第二步**：使用一个小技巧，使我们可以方便地将近似后验插入等式中——添加和减去相同的项不应影响等式。

3. **第三步**：插入对近似后验的期望。为什么允许这样做？因为我们事先知道 \(\log p(x^{(i)})\) 是一个常数。它只是在真实分布下发生示例的概率的对数，是固定的。因此，在等式的左侧进行期望不会改变任何东西，因为常数的期望就是常数本身。

4. **第四步**：将对数组合成商，并利用期望的线性性得到两个项的和：
   - 近似后验与真实后验之间的 KL 散度
   - ELBO（证据下界）

## KL散度的两种形式

到目前为止，您可能已经注意到 KL 散度的形式与我们在第二章中遇到的略有不同。回想一下之前介绍的标准 KL 散度，其中真实分布是 \(p(x)\)，其近似值是 \(q(x)\)。我们定义的 KL 散度是两个分布的交叉熵与真实分布的熵之间的差异，表达如下：

\[
\mathbb{E}_{p(x)} \left[ \log \frac{p(x)}{q(x)} \right]
\]
