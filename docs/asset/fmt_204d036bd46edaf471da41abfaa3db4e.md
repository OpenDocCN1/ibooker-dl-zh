
最优鉴别器永远无法准确知道图像的确切来源，除非生成器无法产生图像，即`p_g(x) = 0`。我们可以量化鉴别器预测的不确定性，作为图像在数据分布下的可能性函数，或者`p_data(x)`，以及在`G`定义的分布下的图像可能性函数，或者`p_g(x)`。如果图像在生成器定义的分布下的可能性小于数据分布下的可能性，那么最优鉴别器应该相应地受到影响，并且应该将图像评分更接近于一而不是零。

### 注意

请注意，一个快速的估算显示这个性质对于得分`p_data(x) / (p_data(x) + p_g(x))`是真实的。但为什么这个性质的确切比例是真实的呢？让我们更具体地看一下得分`p_data(x) / (p_data(x) + p_g(x))`并确定为什么这是两个概率的最优函数。

从我们关于完全混淆的鉴别器的讨论中获得一些启示，我们可以用条件概率的术语来表达所提出的最优鉴别器得分：

```
p(x|y=dataset) / (p(x|y=dataset) + p(x|y=generator))
```

此外，假设从数据集中抽样与从生成器中抽样具有相同的概率（`p(y=dataset) = p(y=generator) = 0.5`），我们可以得到一个更具解释性的最优得分表示：

```
D*(x) = p(x|y=dataset) / (p(x|y=dataset) + p(x|y=generator))
```

```
= p(x|y=dataset) * p(y=dataset) / (p(x|y=dataset) * p(y=dataset) + p(x|y=generator) * p(y=generator))
```

```
= p(x, y=dataset) / p(x)
```

```
= p(y=dataset|x)
```

第三个等式中的分母是通过边缘化`y`得到的结果。最终结果只是在给定输入图像的情况下从数据集中抽样的条件概率。最优鉴别器，`p_θ*(y=dataset|x)`，应该努力匹配输入图像来自数据集的真实概率，`p(y=dataset|x)`。

现在，我们考虑为什么之前定义的极小极大目标由`p(y=dataset|x)`或在固定生成器的假设下给定图像`x`时从数据集中抽样的真实条件概率最大化。让我们仔细观察目标，并尝试以更具信息性的方式重新表述它，这可能为我们提供一些见解：

```
V(G, D) = 𝔼_{x∼p_data(x)} [log D(x)] + 𝔼_{z∼p(z)} [log (1 - D(G(z))]
```
