
从压缩角度看，模糊副本是一种新界面，将分散的文档转化为综合答案和行动。当模型被迫进行无依据生成时，对这种综合的信心应该更低，即使 `MDL` 式预测可以在工具上有用。

最终，变得不那么相关的不是网络本身，而是人类导航它的方式以及我们围绕它建立的机器。搜索引擎、网站、浏览器，以及大部分“searchandstitch”软件开发——主要就是查东西并把片段粘在一起——今天都因为 `AI` 学习有效数据压缩的能力而价值降低。

从 `Chiang` 的视角看，这种损失是缺陷，压缩是档案；从 `Sutskever` 的视角看，压缩是新界面而非副本。当我们驱动机器进行预测和压缩时，简单性在压倒性的复杂性中浮现。
