
在 2011 年，Vincent 探讨了使用`p_σ(x')`作为参考的可能性，而不是我们在显式分数匹配中使用的`p(x)`。这样做的原因是`p_σ(x')`可以被视为对真实分布`p(x)`的连续近似。由`p_data(x)`定义的近似是无偏的，但不幸的是，由于它是数据集中所有图像的均匀分布，在数据集中不存在的地方是不连续的，其概率在其他地方都为零。当然，随着`σ`变大，`p_σ(x')`被视为对`p(x)`的近似越来越不忠实，因此我们希望使用小的`σ`。

Vincent 在 2011 年首次提出了使用`p_σ(x')`作为参考的显式分数匹配：

```
J(θ) = 𝔼_{p_σ(x')} [ 1/2 || ∇_{x'} log p_θ(x') - ∇_{x'} log p_σ(x') ||_2^2 ]
```

```
θ* = argmin_θ J(θ)
```

请注意，为什么这是一个有效的优化过程对于`p_θ(x)`的推理与前一节中的相同——唯一的区别在于我们试图匹配的参考分布。Vincent 2011 实际上走了一步额外，并展示了这个优化过程等效于：

```
J_DSM(θ) = 𝔼_{p_σ(x, x')} [ 1/2 || ∇_{x'} log p_θ(x') - ∇_{x'} log p_σ(x'|x) ||_2^2 ]
```

```
θ_DSM* = argmin_θ J_DSM(θ)
```

虽然我们不会在这里展示证明，并将您转至 Vincent 2011 以获取完整细节，但它确实利用了我们在“实现 VAE”中描述的对数技巧。我们将优化这个目标称为*去噪得分匹配*，简称为*DSM*，正如我们将很快展示的那样，它作为与去噪自编码器的连接。

我们知道`p_σ(x'|x) = N(x'; x, σ²I)`，现在计算其对数的梯度：

```
∇_{x'} log p_σ(x'|x) = ∇_{x'} log ( 1 / √((2π)^d |σ²I|) e^{ -(x' - x)^T (x' - x) / (2σ²) } )
```
